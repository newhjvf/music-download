# История версий

Номер версии `vМАЖОР.МИНОР.ПАТЧ`:
- **ПАТЧ** (v1.1.**1**) — исправления ошибок, мелкие улучшения;
- **МИНОР** (v1.**2**.0) — новые возможности;
- **МАЖОР** (v**2**.0.0) — большая переделка (например, новый интерфейс) или несовместимые изменения.

Версия записана в `musicdl/__init__.py` и `pyproject.toml`, показывается в заголовке окна.

## v1.1.0
- Версии в формате `vX.Y.Z` вместо даты.
- Поиск и скачивание по названию (текстом, по одному треку в строке).
- Недостающие данные трека (альбом, год, обложка, номер трека) подтягиваются из Spotify; альбом всегда записывается в теги.
- Загрузка идёт в несколько потоков (по умолчанию 3), пока один трек конвертируется, скачиваются следующие.
- Если найденный файл не скачался (DRM, 403, вход в аккаунт), берётся запасной источник.
- Из окна убраны проценты и анимация загрузки, окно меньше «зависает».
- «CSV из TuneMyMusic» → «CSV».
- Исправлена ошибка в журнале (`%d` и словарь), SoundCloud: при отсутствии доступа к оригиналам лишние запросы не делаются.

## v1.0.0
- Поиск по YouTube Music, Bandcamp, SoundCloud и YouTube, официальные загрузки в приоритете, отсев ремиксов, каверов, игровых видео.
- Скачивание в mp3 (spotDL), CSV и ссылки Spotify, самообновление с GitHub, окно со счётчиками.
