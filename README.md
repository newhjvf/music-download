# musicdl

Личная программа с окном и кнопками: скачивает музыку в mp3 по списку треков.

- **Вход 1 (основной):** CSV-файл, выгруженный из [TuneMyMusic](https://www.tunemymusic.com/). Работает **без Spotify**.
- **Вход 2:** ссылка Spotify на трек, альбом или плейлист. **Premium и ключи не нужны.**

Файлы сохраняются как `Исполнитель - Название.mp3`, с тегами (исполнитель, название, альбом) и обложкой.

Под капотом используется [spotDL](https://github.com/spotDL/spotify-downloader) 4.5.2 (лицензия MIT). Он ищет трек на YouTube Music, скачивает его через yt-dlp, конвертирует в mp3 через ffmpeg и записывает теги.

## Установка на Windows (один раз)

### 1. Установите Python

1. Откройте https://www.python.org/downloads/windows/ и в разделе *Stable Releases* нажмите **Download Windows installer (64-bit)** у самой новой версии.
2. Запустите скачанный файл. В первом окне **обязательно поставьте галочку «Add python.exe to PATH»**, затем нажмите **Install Now**.

### 2. Скачайте программу

1. На странице https://github.com/newhjvf/music-download нажмите зелёную кнопку **Code → Download ZIP**.
2. Распакуйте архив (правый щелчок → «Извлечь всё…»), например в `C:\musicdl`.

### 3. Запустите установку

Дважды щёлкните по файлу **`install.bat`** в распакованной папке. Откроется чёрное окно. Подождите несколько минут, пока не появится надпись «Готово!».

Установщик сам:
- поставит spotDL и всё нужное;
- скачает ffmpeg;
- создаст на рабочем столе ярлык **musicdl**.

> Если Windows покажет синее окно «Windows защитила ваш компьютер», нажмите **Подробнее → Выполнить в любом случае**.

## Как пользоваться

Запустите программу ярлыком **musicdl** на рабочем столе (или файлом `start.bat`).

1. **Откуда брать треки.**
   - **CSV-файл из TuneMyMusic**: на tunemymusic.com выберите свой плейлист как источник и **Export to file → CSV** как назначение. Затем в программе нажмите **«Выбрать файл…»**.
   - **Ссылка Spotify**: в Spotify «Поделиться → Копировать ссылку», затем в программе **«Вставить»**. Подходят трек, альбом и **публичный** плейлист. Закрытый плейлист без ключей не виден: сделайте его публичным или выгрузите через TuneMyMusic.
2. **Куда сохранять**: по умолчанию папка `Музыка\musicdl`, её можно сменить кнопкой **«Выбрать папку…»**.
3. Нажмите **«Проверить (без скачивания)»**. В таблице будет видно, что нашлось на YouTube Music и какой длины. Двойной щелчок по строке откроет найденное видео в браузере.
4. Если всё устраивает, нажмите **«Скачать»**. Статус каждого трека обновляется в таблице.
5. Кнопка **«Открыть папку с музыкой»** открывает папку со скачанным. **«Открыть список ненайденных»** — таблицу с тем, что не нашлось (открывается в Excel).

Полезно знать:
- Уже скачанные треки при повторном запуске **пропускаются**. После ошибок сети можно просто нажать «Скачать» ещё раз.
- **«Одновременно»** — сколько треков качать параллельно. Если много ошибок, поставьте 1–2.
- **«Только официальные треки»** — не брать клипы, концертные записи и каверы.
- Программа запоминает последние настройки.

## Обновления

Программа обновляется **сама**. При каждом запуске она на пару секунд показывает «Проверяю обновления…». Если на GitHub появилась новая версия, программа скачает её, перезапустится и напишет внизу окна «Программа обновлена».

- Музыка, настройки, файл `.env` и установленные компоненты при обновлении не трогаются.
- Если интернета нет, программа просто запустится без обновления.
- Обновление ставится только при запуске: чтобы его получить, закройте программу и откройте снова.

## Для продвинутых: командная строка

Те же функции доступны из `cmd` в папке программы:

```bat
.venv\Scripts\activate
musicdl csv my.csv --dry-run
musicdl csv my.csv --out "D:\Музыка"
musicdl url "https://open.spotify.com/playlist/..."
```

| Параметр | Что делает |
|---|---|
| `--dry-run` | только поиск и таблица «трек → найденное видео + длительность», без скачивания |
| `--out ПАПКА` | куда сохранять (по умолчанию `music`) |
| `--threads 4` | сколько треков качать параллельно |
| `--bitrate 320k` | качество mp3 (`128k`, `192k`, `256k`, `320k`) |
| `--report файл.csv` | куда записать список ненайденных (по умолчанию `ПАПКА\not_found.csv`) |
| `--only-verified` | только официальные треки YouTube Music |
| `-v` | подробный лог |

Ручная установка без `install.bat`:

```bat
py -m venv .venv
.venv\Scripts\activate
pip install -e .
spotdl --download-ffmpeg
```

## Необязательно: ключи Spotify

Без них всё работает. Ключи нужны, только если хотите использовать официальный Spotify API. С февраля 2026 года Spotify требует для этого **Premium**.

1. Создайте приложение на https://developer.spotify.com/dashboard и скопируйте *Client ID* и *Client Secret*.
2. Скопируйте `.env.example` в `.env` (рядом с README) и впишите ключи:
   ```
   SPOTIFY_CLIENT_ID=ваш_id
   SPOTIFY_CLIENT_SECRET=ваш_secret
   ```
   Файл `.env` не попадает в git.

## Если что-то не работает

| Что случилось | Что делать |
|---|---|
| `install.bat` пишет «Python не найден» | переустановите Python с галочкой «Add python.exe to PATH» |
| окно программы не открывается | запустите `install.bat` ещё раз; если не помогло, пришлите файл `log.txt` из папки `C:\Users\ВАШЕ_ИМЯ\.musicdl` |
| много «не найдено» или «ошибка поиска» | YouTube временно ограничивает запросы: подождите, поставьте «Одновременно» 1–2, включите VPN |
| найдено не то | сначала нажимайте «Проверить», попробуйте «Только официальные треки» |
| ошибка про колонки CSV | нужен экспорт TuneMyMusic с колонками *Track name* и *Artist name* |
| ошибки после обновлений YouTube | обновите загрузчик: в папке программы `.venv\Scripts\python -m pip install -U yt-dlp` |

Кнопка **«Журнал ошибок»** в программе открывает файл с подробностями. Его можно прислать разработчику.

## Как это устроено (для разработчика)

| Задача | Чем делается |
|---|---|
| объект трека | `spotdl.types.song.Song.from_missing_data`, собирается из строки CSV (`musicdl/csv_import.py`) |
| поиск и сопоставление | `spotdl.providers.audio.ytmusic.YouTubeMusic.search` и `spotdl.utils.matching.order_results` (`musicdl/matching.py`) |
| скачивание, ffmpeg, ID3, обложка | `spotdl.download.downloader.Downloader` (`musicdl/job.py`, `musicdl/pipeline.py`) |
| окно с кнопками | tkinter из стандартного Python (`musicdl/gui.py`) |
| автообновление | ZIP ветки `main` с GitHub, только стандартная библиотека (`musicdl/updater.py`); копия с папкой `.git` не обновляется |
| ссылки Spotify | `spotdl.utils.spotify.SpotifyClient` и `spotdl.utils.search.parse_query` (`musicdl/spotify_input.py`) |

Собственного кода немного. Вот что в нём есть сверх spotDL:

- **Разбор CSV TuneMyMusic.** Поддерживаются UTF-8 с BOM, разделители `,` `;` и табуляция, а также удаление дублей.
- **Поиск без длительности трека.** В CSV нет длительности, а spotDL отбрасывает все результаты, если длительность неизвестна. Для таких треков оценка идёт по названию, исполнителю, альбому и ISRC. Треки с известной длительностью (из Spotify) сопоставляются как в spotDL без изменений.
- **Однократный поиск.** Найденная ссылка передаётся в `Downloader`, повторного поиска нет. Обложка для треков из CSV берётся с превью YouTube.
- **Таблица `--dry-run`, пропуск уже скачанных и `not_found.csv`.** Тексты песен не скачиваются (`lyrics_providers=[]`).

Версия spotDL закреплена на `4.5.2`. В версии 4.5.0 вошёл [PR #2626](https://github.com/spotDL/spotify-downloader/pull/2626): клиент Spotify без ключей после изменений API в феврале 2026 ([issue #2617](https://github.com/spotDL/spotify-downloader/issues/2617)). 4.5.2 — последний релиз с последующими исправлениями.

Окно и командная строка используют один и тот же движок `musicdl/job.py`.

Тесты (без сети, YouTube подменяется заглушками):

```bat
pip install -e .[dev]
pytest
```

Используйте программу только для музыки, которую вы вправе скачивать.
